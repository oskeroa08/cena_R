# ЦЕНА РЕШЕНИЯ — сайт

Чистый HTML/CSS/JS, без сборки. Файлы: index.html, salon.html, company.html, privacy.html (заглушка), styles.css, script.js, assets/.

Перед запуском:
- script.js: CONTACT_EMAIL (сейчас oskeroa08@gmail.com), METRIKA_ID, функция submitToCrm() для подключения CRM.
- privacy.html: заменить заглушку утверждённой политикой обработки персональных данных.
- Фото: на месте блоков «Фото: …» (.photo .slot) вставить <img src="assets/..."> с реальными фотографиями.
- Заявки пока уходят через почтовую программу посетителя (mailto); для надёжной доставки подключить CRM или обработчик формы на сервере.
