# ЦЕНА РЕШЕНИЯ — сайт

Чистый HTML/CSS/JS, без сборки и без внешних подключений (шрифты, счётчики, скрипты третьих сторон не используются).
Файлы: index.html, salon.html, company.html, styles.css, script.js, assets/.

Сайт не собирает персональные данные: вместо формы в блоке «Обсудить проведение» — кнопки «Написать на почту», «Позвонить» и (когда будет указана ссылка) «Написать в MAX».

## Контакты
Телефон, почта и реквизиты ИП указаны в разметке страниц (блок `.contact` и подвал). Ссылка на чат MAX и QR-код при необходимости добавляются в генератор страниц (`MAX_URL`, `MAX_QR`) либо вручную: карточка `.ccard` в блоке `#contact` и строка в подвале.

## Фотографии
Блоки «Фото: …» — это заглушки. Положите изображения в `assets/photos/` (jpg, до ~1600 px по ширине, не тяжелее 300 КБ) под именами:
- `home-adapt.jpg` — главная, «Адаптация под вашу компанию»
- `salon-hero.jpg` — салон, первый экран
- `salon-partners.jpg` — салон, «Для производителей и дилерских сетей»
- `company-hero.jpg` — компания, первый экран
- `company-adapt.jpg` — компания, «Адаптация под компанию»

## Кэш
Версия файлов указана в адресах (`styles.css?v=…`, `script.js?v=…`): при изменении этих файлов меняйте значение `v`.

## Аналитика
`METRIKA_ID` в script.js — счётчик Яндекс Метрики (сейчас не подключён). Цели: клики по кнопкам связи (`data-goal`).
