# ЦЕНА РЕШЕНИЯ — сайт

Чистый HTML/CSS/JS, без сборки и без внешних подключений (шрифты, счётчики, скрипты третьих сторон не используются).
Файлы: index.html, salon.html, company.html, privacy.html (политика), styles.css, script.js, assets/.

## Настройки (script.js, в начале файла)
- `CONTACT_EMAIL` — адрес, на который формируется письмо с заявкой.
- `MAX_CHAT_URL` — ссылка на чат в MAX. Если указать, при выборе способа связи «MAX» под полем появится ссылка перехода в чат.
- `METRIKA_ID` — счётчик Яндекс Метрики (сейчас не подключён; подключать только после обновления Политики).
- `submitToCrm()` — точка подключения CRM / обработчика форм (сейчас заявка уходит письмом из почтовой программы посетителя).

## Форма и согласие
- Поля: имя, способ связи (e-mail / MAX) и контакт, компания и должность (необязательно), формат, комментарий (до 1000 символов, фиксированный размер).
- Согласие: отдельный чекбокс (по умолчанию не отмечен), без него отправка невозможна; текст согласия показан до отправки, ссылка на Политику — отдельно.
- В письмо с заявкой автоматически добавляются сведения о согласии: версия текста, дата и время, страница, браузер.
- Версия текста согласия задаётся при сборке (`CONSENT_VERSION` = «1.0 от 12.11.2026»). При изменении текста согласия или Политики обновите версию и дату.

## Перед запуском
- Подтвердить фактический маршрут заявки (адрес получателя, почтовый сервис) и привести Политику (privacy.html, раздел 6) в соответствие.
- Подать уведомление оператора в Роскомнадзор до начала сбора данных.
- Заменить блоки «Фото: …» (`.photo .slot`) реальными фотографиями.
